Your own website

                

                  
⇩

                  
Drag a website folder or .zip here

                  
Any static site with an index.html (hand-written, or a built React / Vue / Hugo / Astro output). It replaces the generated pages; anything it does not define still falls back to them and to the API.

                

                

                

                  
                  
                

                
Show live server data in your site
                  
Add <script src="/dayz-status.js"></script> to your page, then put data-dayz="…" on any element: online, players, max, uptime, next-restart, restart-times, mods-count. Use data-dayz-list="mods" or "players" on a <ul> for lists. It refreshes every 30 seconds, and raw JSON is at /api/status.json.

                

              

              

                
Custom files

                
Anything in this folder is served by the site: images, fonts, extra HTML pages. Reference them as /name.ext. Special files take over parts of the site:

                
    
                  
  • template.html replaces the layout. Placeholders: {{site}}, {{title}}, {{nav}}, {{content}}, {{year}}.
    • 
                  
  • index.html replaces the home page entirely. Live data is at /api/status.json and /api/mods.json.
    • 
                  
  • site.css replaces the generated stylesheet; mods.html or <slug>.html replace a single page.
